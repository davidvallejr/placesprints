Webhook da planilha de custos

O segredo aparece só agora. Copie o Apps Script pronto (ou a URL e o segredo) antes de fechar: depois ele não é mostrado de novo — perdeu, rotacione. Cole direto no Apps Script (não mande por e-mail/WhatsApp) e use um webhook por planilha: a cópia da planilha leva o segredo junto.

URL

Segredo (mostrado uma única vez)

  1. Na planilha, aba Custos: A = SKU (formato “Texto simples”), B = MLB (opcional), C = Custo, D = Status (o script escreve). Linha 1 = cabeçalho.
  2. Extensões → Apps Script: apague o conteúdo do arquivo, cole o script e salve.
  3. Rode a função instalar uma vez e autorize; depois apague a função instalar (o segredo fica só nas propriedades do script).
  4. Menu Custos → Sincronizar agora: a coluna Status mostra OK, EM ANÁLISE, RECUSADO no painel ou REJEITADO por linha.
