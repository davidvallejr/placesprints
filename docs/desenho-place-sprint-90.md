## 4. Fluxos ponta a ponta

1. **Compra**: landing → plano → dados → aceite (checkbox "Li e aceito os Termos v… e a Política; sei que a autorização do Mercado Livre inclui permissão de escrita, usada só após a minha aprovação") + consentimento LGPD (checkbox separado) → `POST /c/assinar` (honeypot, limite IP, vagas em transação, MP configurado) → `cadastrar` (aceite com versão/hash/IP/UA/e-mail/plano/preço) → `criarPreapproval` → cookie de sessão → redirect `init_point` (cartão de teste no piloto).
2. **Webhook**: `subscription_preapproval`/`subscription_authorized_payment`/`payment` → HMAC → INSERT OR IGNORE → GET no recurso → `aplicarPagamento` (centavos conferidos) → `ativo`, `inicio_em`; falha → 500/reenvio + tick.
3. **Provisionamento**: `ativo` cria nada no Notion; `s90_evento 'estado'`; aviso interno "nova conta S90" com `link:'/integracoes'`.
4. **Acesso**: `GET /c/retorno` (cookie) → `buscarPreapprovalPorRef` (authorized → ativo se o webhook ainda não chegou) → link de 30 d "guarde este link" (uma vez) + botão **Conectar o Mercado Livre**. Sem cookie → "acesso liberado pela equipe" + aviso interno com `external_reference`.
5. **Conexão ML**: `/c/conectar` (sessão) → `linkConectar(chave,1)` → `/meli/conectar` → callback: `aoConectar` (D17) → `salvarConexao` → coleta + acompanhamento + `gerarPlanoConta` em segundo plano → redirect `/c/painel?conectado=1`. Reconexão idêntica (faixa no painel quando `meli_contas.erro`).
6. **Dia 0**: painel mostra "lendo sua conta" até `coberturaPedidos`; depois Resumo (diagnóstico, estado da conta, fase "Dia 1 de 90 · Estruturação" derivada de `inicio_em`, prova da fase calculada, nunca concluída por calendário), pendências de dados (custos %, tributos, regra, catálogo próprio = declaração rotulada).
7. **Semana típica**: madrugada = coleta → acompanhamento → `gerarPlanoConta` (regras de consultor já fora; `fila='esta_semana'` = até 5). Cliente abre Prioridades: cada cartão = anúncio (foto/link), problema com número, fato × hipótese, impacto com premissas/cenários, e **Executa** (Aprovar → `executar` abre job) ou **Recomendação** (roteiro + Vou fazer / Fiz / Descartar). 8. **Otimização campo a campo**: `executar` → `importarExistente` → `abrirJob` (ação `aprovada`) → GATE 0 ("estas fotos são do seu produto?" com `pictures` do snapshot; checkbox) → `confirmarReferencia` → `prepararEstrategia` → proposta v1 (ficha com fonte/evidência, descrição por regra, preço com piso/margem ou bloqueio "informe custos", título só quando `capacidades.pode.titulo`) → cliente aprova/reprova campo a campo presa à versão (`ofertas.js:717-736`); `revisar` invalida aprovações; imagens só com FAL_KEY (cada candidata aprovada; galeria montada por `revisar`). 9. **Conferência**: tick 30 min depois → `conferir` → `publicado_confirmado` (ou `aguardando_canal` → nova consulta agendada; `falha_parcial` → pendência exibida em texto fixo, nunca "publicado").
10. **Medição**: `execucoesOfertas` (`impacto-tarefas.js:435-450`) para jobs publicados/verificados; tarefas `s90` para "fiz"; marcos 24h/48h/72h/7d (`acompanhamento.js:321-339`); `monitorar` diário; retroalimentação por família × estado; calibração vê `distribuida`.

## 6. Segurança e LGPD

| Ataque | Defesa |
|---|---|
| `?cliente=` / `body.cliente` nas APIs | `/c/api/*` ignora; cliente = sessão; painel interno segue 403 pelo túnel |
| Roubo/forja de sessão | 128 bits, só hash, HttpOnly/Secure/Lax/Path=/c, 30 d deslizante, revogação em `/c/sair`, `no-store` |
| Reuso do link mágico | uso único (UPDATE condicional), 15 min (equipe) / 30 d (retorno/painel), 404 uniforme, IP no evento |
| CSRF | guarda já exige Origin==Host em mutação (`guarda-local.js:27`); Lax; `form-action 'self'` |
| XSS / clickjacking | `esc()` + DOM; CSP com nonce; `X-Frame-Options: DENY` |
| Host spoofing / rebinding / painel interno pelo host S90 | lista fechada por host exato; `/c/*` inexistente nos outros hosts; `%2f/%5c/..` = 403; estático nunca passa |
| Força bruta (`/c/acesso`, `/c/assinar`) | 2^128; 10/15 min e 5/h por IP//64; honeypot; respostas uniformes |
| Webhook forjado / replay | HMAC fechado sem segredo; janela ts; releitura por GET; `external_reference` tem de casar; `s90_mp_evento` + idempotência por (payment,status); bloqueio de IP por falha de HMAC |
| Valor manipulado / pagamento órfão / duplicado | preference/preapproval só no servidor; centavos relidos; `divergente`; `orfao` + aviso; UNIQUE por competência |
